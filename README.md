# Дубли вкладок

Расширение для Google Chrome ищет уже открытые копии веб-страниц во всех окнах текущего профиля. Данные обрабатываются локально.

## Установка

1. Откройте `chrome://extensions` в Chrome.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите эту папку, в которой находится `manifest.json`.
4. В меню расширений нажмите **Дубли вкладок**. При желании закрепите значок на панели Chrome.

## Использование

- Нажмите на значок расширения, чтобы открыть список дублей. Если вкладки изменились, нажмите **Обновить**.
- Разверните группу, чтобы увидеть номера окон и вкладок. Кнопка **Перейти** откроет нужную вкладку в её окне, а **Оставить эту** выберет копию для сохранения.
- Закрывайте дубли по одному, по группе или кнопкой **Закрыть дубли**. Если вы ввели текст в фильтр, общая кнопка действует на все найденные фильтром группы, включая следующие страницы результатов. Перед закрытием Chrome покажет подтверждение на вкладке расширения.
- Кнопка **Закрыть всю группу** закроет все её вкладки после подтверждения, включая выбранную для сохранения, закреплённые и вкладки со звуком.
- По умолчанию параметры после `?` игнорируются, а фрагмент после `#` учитывается. Чтобы сравнивать полные адреса, включите **Учитывать параметры URL после ?**. Настройка сохраняется между запусками Chrome.

Расширение проверяет HTTP- и HTTPS-страницы. При закрытии дублей оно сохраняет выбранную копию, закреплённые вкладки и вкладки со звуком. По умолчанию оно выбирает защищённую, активную или недавно использованную вкладку. Перед закрытием оно сверяет актуальный список вкладок с выбранным действием.
